# 装柜计算：参数、算法与结果解读

## 1. 输入口径

工作台里的“货物”是**一个外箱或一个整托**：

| 字段 | 口径 |
|---|---|
| 长/宽/高 | 外箱净尺寸 cm（包装前）；勾选“整托”时用托盘长宽 |
| 数量 | 箱数（不是件数） |
| 净重/箱 | 箱内货物重量 kg |
| 皮重/箱 | 纸箱/木箱重量 kg |
| 每箱数量 | 件/箱，仅用于生成单证，不参与排布 |
| 毛重/箱 | 自动 = 净重 + 皮重（整托时 + 托盘重） |

包装填充两种算法：

- **厚度**：有效尺寸 = 净尺寸 + 2 × 单边厚度（气泡膜 +1、珍珠棉 +3、隔板 +2 cm）。
- **填充率**：按体积比例放大，边长统一乘 `∛(1/(1-r))`，r 上限 90%。

## 3. 排布算法（分区整排堆码）

1. 按货物体积从大到小排序，一种货物占一条“车道”（沿柜长方向的整宽区块），车道在柜宽方向居中。
2. 对每种货物尝试所有允许的摆放方向（任意/竖放/横放/固定，易碎品锁定竖放），计算：
   - `nx = floor(柜宽 / (箱宽 + 侧隙))`
   - `ny = floor(柜高 / (箱高 + 层隙))`，再被“最大堆码层数”“单箱承压”封顶
   - 每排 `nx × ny` 箱；所需长度 = `ceil(数量 / (nx×ny)) × (箱长 + 长隙)`
3. 选**所需柜长最短**的方向，从当前柜长位置向后排，逐层、逐列放置。
4. 重量达到限重即停止，剩余箱数记为“超重未装”；车道超过柜长即停止，剩余记为“空间不足”。
5. 同一车道内每列从下往上连续堆码，底层承受整列重量。

### 为什么按货物分区，而不是混装

混装（不同箱规互相插空）在数学上是 3D bin packing，启发式算法很容易碎片化：实测同一批 38.4 m³ 的货，混装算法只装进 19.9 m³（26%），分区堆码能装满。分区也符合仓库实际：一种货一个垛位，点数、拆柜都方便。代价是不同货物之间不互相插空，空间利用率略低。

## 4. 结果指标

| 指标 | 算法 | 健康区间 |
|---|---|---|
| 货物体积 | 已装箱体净体积（含包装，不含间隙/托盘） | 与订单 CBM 对照 |
| 总毛重 | 已装箱数 × 单箱毛重 | ≤ 限重 |
| 空间利用率 | 箱体占位（含间隙/托盘）/ 柜内体积 | 50%–75% 正常，>85% 很紧 |
| 装载进度 | 已装 / 应装箱数 | 全部装入最佳 |
| 重量饱和度 | 总毛重 / 限重 | <90%；≥90% 红色 |
| 剩余载重 | 限重 − 总毛重 | 越大越安全 |
| 重心横向偏移 | (货重加权重心 X − 柜宽/2) / 柜宽 | ±10% 内好；>20% 红 |
| 底层最大压强 | (箱重 + 上方载荷) × 9.80665 / 底面积 m² / 1000 | 与纸箱抗压比较 |
| 本柜占长 | 已用柜长 / 柜内长 | 判断还能加多少货 |

**重心**：分区居中后通常接近 0；偏得大说明各货区宽度差异大，重货应尽量靠柜宽中线、靠柜底。

**底层压强**：普通出口纸箱抗压约 3–8 kN，按底面积换算常见 5–15 kPa；超过 15 kPa 要确认纸箱配纸和堆码层数，或加托盘/隔板。

## 5. 装不下时怎么调

先看提示是“超重”还是“空间不足”。

**超重**
- 减少数量，或把重货移到下一个柜；
- 换限重更高的柜型（20GP 限重通常高于 40HQ）；
- 核对单箱毛重是否把托盘/木架重复计入。

**空间不足**
- 摆放方向：`任意` 通常最优；`固定` 会浪费 10%–30%；
- 间隙：标准 0、防涨 +1/+2、木架 +3 cm，木架最占体积；
- 托盘：整托会按托盘长宽占位，矮箱上托盘通常不划算；
- 堆码层数/承压：设了上限会提前封顶；
- 箱规是否填成了内尺寸而不是外箱尺寸；
- 货物种类太多、每种量又小：分区会浪费车道，考虑合并箱规或拼柜。

## 6. 柜数估算

工具按体积和重量双约束粗算：

```
n = max( ceil(总CBM / (柜容积 × 0.85)), ceil(总毛重 / (限重 × 0.90)) )
```

这是**下限估算**。实际还要看箱规是否匹配（超长/超宽箱、不能翻转的货）、目的港限重、是否允许叠放。最终以装柜图/货代确认为准。

## 7. 已知边界

- 一次只模拟**一个**柜；超出部分提示未装，柜数用上面的公式估。
- 不做轴荷、道路限重、绑扎/加固、危化品、冷藏柜、开顶柜/框架柜。
- 不处理“同一车道内不同货种上下叠放”，也不做车厢内多停靠点卸货顺序。
- 尺寸单位为 cm，重量 kg；所有结果保留两位小数。

需要这些能力时，明确告诉用户“本工具只做单柜体积/重量可行性初算”，并建议货代复核。
